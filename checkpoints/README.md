# Checkpoints

Each file is the state of `src/app.js` at the **start** of that step: every earlier
step finished, the current step still TODO.

Use one if you fall behind, or if you want to jump straight to a later step:

```bash
cp checkpoints/step-06.js src/app.js
```

In StackBlitz there is no terminal by default - open the checkpoint file, select
all, copy, and paste over `src/app.js`.

| File | Gives you | Leaves you to do |
| --- | --- | --- |
| `step-01.js` | the empty starter (same as `src/app.js`) | step 1 |
| `step-02.js` | step 1 finished | step 2 |
| `step-03.js` | steps 1-2 finished | step 3 |
| `step-04.js` | steps 1-3 finished | step 4 |
| `step-05.js` | steps 1-4 finished | step 5 |
| `step-06.js` | steps 1-5 finished | step 6 |
| `step-07.js` | steps 1-6 finished | step 7 |
| `step-08.js` | steps 1-7 finished | step 8 (the capstone) |

Reading ahead is allowed and encouraged - but you will learn more from the trap in
step 8 if you hit it yourself first.
